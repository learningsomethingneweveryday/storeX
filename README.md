# 🛍️ storeX – E-Commerce Store

**storeX** is a modern e-commerce website designed to provide users with a simple and convenient online shopping experience.

The project demonstrates the development of an online store with a focus on product browsing, user-friendly navigation, and a responsive interface.

## 📌 About the Project

storeX was created as a web development project to practice building an online shopping platform.

The application provides a structured way for users to explore products and interact with an online store interface.

## ✨ Features

* 🛍️ Product browsing
* 🔎 Product search
* 🗂️ Product categories
* 🛒 Shopping cart
* ❤️ Wishlist functionality
* 📄 Product details
* 💳 Checkout interface
* 📱 Responsive design
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/learningsomethingneweveryday/storeX.git
```

### 2. Open the project

Open the repository in **VS Code**.

### 3. Run the website

Open the main HTML file in your browser.

For a better development experience, you can use the **Live Server** extension in VS Code.
